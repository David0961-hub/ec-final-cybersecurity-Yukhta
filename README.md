# Портал направления «Кибербезопасность» (Инженерный колледж)

Веб-приложение для абитуриентов и студентов направления «Кибербезопасность» (Тема 2).

## Стек технологий
- React 18 + Vite
- React Router DOM
- CSS3 (адаптивная вёрстка)

## Запуск проекта локально
```bash
git clone https://github.com/David0961-hub/ec-final-cybersecurity-Yukhta.git
cd ec-final-cybersecurity-Yukhta
npm install
npm run dev
```
